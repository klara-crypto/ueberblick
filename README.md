# Klaras Überblick

Persönliche To-do-App (Aufgaben, Ideen, Termine, Reisen, Geld) als Web-App für den Home-Bildschirm.

- `index.html` ist die ganze App. Daten liegen bei Supabase, getrennt pro Konto.
- `config.js` enthält Supabase-Adresse und öffentlichen anon-Schlüssel.
- `supabase-schema.sql` legt die Tabelle mit Zeilen-Sicherheit an.
- Persönliche Daten gehören nicht in dieses Repo. Deine Aufgaben liegen nur in der Datenbank.
